# Cookie Notice (plg_system_cookienotice)

**Simple. Absolutely free. For any Joomla site.**

A lightweight system plugin that shows a cookie consent banner. Useful for many kinds of sites as part of cookie / privacy notices (including approaches related to GDPR and similar rules). Configure your own message, privacy-policy link, and button labels.

- **Joomla:** 5.x and 6.x  
- **License:** GNU GPL version 2 or later  
- **Price:** Free - no fees, no locked features, no domain limits  
- **Download:** [plg_system_cookienotice-1.0.3.zip](dist/plg_system_cookienotice-1.0.3.zip)  
- **Author:** artrook1  
- **Updates:** Joomla Extension Update using [`updates.xml`](updates.xml) in this repository  

## Install

1. Download the zip from this repository (or from the Joomla Extensions Directory listing when published).
2. In Joomla: **System → Install → Extensions** and upload the zip.
3. Enable **System - Cookie Notice** if it is not already enabled.
4. Configure the message and privacy URL under the plugin options.

Existing acceptances that use the cookie name `cookieAcceptanceCookie` continue to work.
